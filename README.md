# Конспектатор — Telegram-бот на базе GigaChat (LLM)

## Описание проекта
Проект представляет собой простой ИИ-бот-ассистент для учебных целей.

Пользователь отправляет боту текст (фрагмент лекции, статьи или конспекта), а бот:
- формирует краткий структурированный конспект,
- выделяет ключевые тезисы,
- определяет важные термины,
- генерирует вопросы для самопроверки.

В проекте используется модель большого языка (LLM) **GigaChat** через официальный Python-SDK.

## Целевая аудитория
- студенты,
- школьники,
- пользователи, которые учат теорию и хотят быстро пересобрать материал в структурированный конспект.

---

## Используемые технологии
- Python  
- Telegram Bot API  
- LLM: **GigaChat API (Сбер)**  
- Библиотеки:
  - `gigachat` — работа с LLM  
  - `pyTelegramBotAPI` — Telegram-бот  
  - `python-dotenv` — конфигурация через файл `.env`

---

## Архитектура 

1. Пользователь отправляет текст боту в Telegram.  
2. Сообщение обрабатывается файлом `bot.py`.  
3. Скрипт формирует системный промпт и обращается к модели GigaChat через API.  
4. LLM генерирует структурированный ответ.  
5. Бот возвращает результат пользователю в чат.

Поток данных:

`Пользователь → Telegram → bot.py → GigaChat LLM → bot.py → Telegram → Пользователь`

## Создать файл .env (по образцу .env.example)

## Сценарии использования

- Конспект лекции — пользователь вставляет текст → бот формирует конспект.
- Подготовка к зачёту — бот выделяет термины и вопросы для самопроверки.
- Повторение материала — пользователь отправляет выдержки из учебника.
- Риски и ограничения
- Возможны неточности и “галлюцинации” LLM.
- Нельзя отправлять конфиденциальные или персональные данные.
- Работа бота зависит от доступности GigaChat API.
